# 👥 Team Roles & Responsibilities

LedgerCore is developed by a dedicated team of four, divided into specialized Frontend and Backend/AI squads to build out these advanced features.

## 🎨 Frontend Squad (Rani & Anshu)
**Focus:** Next.js, Tailwind CSS, UI/UX, State Management, and Data Visualization.
*   **Rani (Frontend Lead / UI Engineer)**:
    *   Set up the Next.js architecture, Tailwind CSS, and component libraries.
    *   Build the core **Employee Dashboard** (Expense Submission forms, Voice Recording UI, Receipt Uploads).
    *   Implement robust state management using Zustand for tracking active claims and user sessions.
*   **Anshu (Frontend Developer / Data Visualization)**:
    *   Develop the **Manager & Admin Dashboards** (Approval workflows, real-time status tracking, color-coded flags).
    *   Build the **Executive Health Dashboard** (Interactive charts for expense tracking and budgeting limits).
    *   Integrate the Natural Language Search UI for advanced querying.

## ⚙️ Backend & AI Squad (Zeel & Saptak)
**Focus:** FastAPI (Python), PostgreSQL, Open-Source Machine Learning, and APIs.
*   **Saptak (Backend Lead / System Architect)**:
    *   Set up the **FastAPI** server and design the **PostgreSQL** database schema.
    *   Implement Role-Based Access Control (RBAC) and secure User Management APIs.
    *   Develop **Payment Gateway Integrations** and the secure local Data Vault (JSON backup/restore logic).
*   **Zeel (AI & Machine Learning Engineer)**:
    *   Integrate **Tesseract/PaddleOCR** for the AI Receipt Scanner.
    *   Deploy **Local LLMs (Ollama)** to power the AI Approval Copilot and Natural Language Search.
    *   Build custom anomaly detection models (Scikit-Learn) for **Expense Risk Scoring** and AI Fraud Detection.
    *   Integrate the open-source **OpenAI Whisper** model for voice-to-text processing.
